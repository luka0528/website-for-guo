## 阿里云个人备案（ICP）核对清单（适用于本项目）

> 目标：`jitaoguo-edu.cn` 面向大陆长期稳定访问，前端 `www`，后端 `api`。

### 0) 域名与实名
- [ ] 购买 `.cn` 域名（不加购“同步搭建轻量网站”）
- [ ] 完成域名实名认证（按万网提示提交）
- [ ] 准备解析规划（可先不生效，备案通过后再正式切）

### 1) 备案主体（个人）
- [ ] 主体类型：个人（老师本人）
- [ ] 证件：身份证信息、手机号、联系地址
- [ ] 网站用途说明（建议用语）：
  - “教师科研成果展示、团队成员介绍、新闻动态发布、注册登录后下载论文与资料。”

### 2) 备案接入信息（阿里云）
- [ ] 备案接入方式：阿里云（ECS/OSS/CDN）
- [ ] 服务器实例信息（ECS）准备好（备案过程中会用到）

### 3) 域名规划（备案后落地）
- [ ] `www.jitaoguo-edu.cn` → 前端静态站（OSS 静态托管 + CDN）
- [ ] `api.jitaoguo-edu.cn` → 后端 API（ECS + Nginx 反代）

### 4) HTTPS 与上线
- [ ] 备案通过后申请证书（阿里云证书或 Let’s Encrypt）
- [ ] Nginx 配置 HTTPS
- [ ] 前端开启全站 HTTPS

### 5) 常见坑提醒
- **备案期间**：域名解析不要指向“可访问的正式站点内容”（按备案要求处理）
- **上线后**：若使用国内 CDN/OSS，通常要求域名已有备案号
